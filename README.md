# Sales CRM

A modern full-stack CRM application built with Angular and NestJS.

## Purpose

This project is being developed as a production-like application to demonstrate modern full-stack development practices, software architecture, and scalable business logic.

## Tech Stack

### Frontend
- Angular (latest)
- TypeScript
- RxJS
- Signals
- Tailwind CSS

### Backend
- NestJS
- PostgreSQL
- Prisma ORM

### DevOps
- Docker
- GitHub Actions
