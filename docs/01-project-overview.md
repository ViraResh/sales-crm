# Sales CRM

## Project Goal

Sales CRM is a web application designed to help small and medium-sized businesses manage clients, sales activities, and internal workflows in one place.

The application replaces spreadsheets and paper-based processes with a centralized system that supports multiple user roles, client management, reporting, and future AI-assisted features.

---

## Target Users

- Sales Representatives
- Managers
- Administrators

---

## Main Goals

- Manage clients
- Track sales
- Monitor team performance
- Generate business insights
- Provide secure role-based access
